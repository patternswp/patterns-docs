# Patterns Docs

> **Patterns Docs** is a clean and professional block-based WordPress theme designed for documentation websites, knowledge bases, wikis, and help centers.

## Description

Patterns Docs is a Full Site Editing (FSE) WordPress theme tailored for documentation websites, knowledge bases, wikis, and help centers. It provides all the tools needed to create a well-structured and user-friendly online resource. With its block-based approach, Patterns Docs allows for seamless customization of headers, footers, layouts, and global styles directly within the WordPress Site Editor.

## Features

- **Full Site Editing (FSE):** Customize every aspect of your website using the WordPress block editor.
- **Structured Design:** Perfect for knowledge bases, wikis, and help centers.
- **Responsive Layouts:** Optimized for seamless display across devices.
- **Pre-designed Templates:** Includes layouts for FAQs, documentation pages, support articles, and more.
- **Custom Block Patterns:** Easily organize content with ready-to-use patterns.
- **SEO Optimized:** Built with best practices for improved search rankings.
- **Lightweight and Fast:** Optimized for high performance and quick load times.

## Getting Started

### Installation

- Clone the repository to your `/wp-content/themes/` directory:

  ```bash
  git clone https://github.com/patternswp/patterns-docs.git
  ```

- Or download and upload the theme files to `/wp-content/themes/patterns-docs`.

### Activate the Theme

Activate the theme via the WordPress admin dashboard under **Appearance > Themes**.

### Start Customization

With Full Site Editing support, you can customize the theme through the WordPress Site Editor by navigating to **Appearance > Editor**. Modify headers, footers, layouts, and global styles to suit your docs needs.
